# Sigilwoven

Хардкорная изометрическая ARPG с системой связанных навыков. Комбинируйте
активные умения с Link-модификаторами, собирайте экипировку и проходите
подземелья возрастающей сложности.

## Скачать игру

Готовая игра находится на странице
[GitHub Releases](https://github.com/g0dblssd/sigilvowen/releases/latest).
Исходный код скачивать и собирать не нужно.

- **Windows 10/11 x64:** `Sigilwoven-Setup-Windows-x86_64.exe`.
- **Linux x64:** `Sigilwoven-Installer-Linux-x86_64.run`.
- ZIP и TAR.GZ — portable-версии без установки.

Godot и .NET отдельно устанавливать не требуется.

Для запуска Linux-установщика:

```bash
chmod +x Sigilwoven-Installer-Linux-x86_64.run
./Sigilwoven-Installer-Linux-x86_64.run
```

## Возможности

- семь классов с собственными навыками, оружием и боевым стилем;
- Link System, изменяющая поведение и эффекты активных навыков;
- развитие до 300 уровня, Paragon и большое дерево пассивных умений;
- процедурная добыча, экипировка, редкости, аффиксы и крафтовые материалы;
- элитные противники, боссы и восемь уровней сложности подземелий;
- сохранение персонажа, предметов и прогрессии между запусками.

## Управление

| Действие | Клавиша |
| --- | --- |
| Движение | удерживать левую кнопку мыши |
| Основная атака класса | правая кнопка мыши |
| Навыки | `1–6`, `Z`, `X`, `C`, `V` |
| Уклонение | `Space` |
| Лечебная фляга | `Q` |
| Подобрать предмет | `F` |
| Взаимодействие с NPC | `E` |
| Инвентарь | `I` |
| Link Forge | `L` |
| Дерево пассивов | `P` |
| Подземелья | `D` |

## Сохранения

- Linux: `~/.local/share/godot/app_userdata/Sigilwoven/`
- Windows: `%APPDATA%\Godot\app_userdata\Sigilwoven\`

## Сборка из исходников

Разработчикам нужны Godot **4.7.2 .NET**, соответствующие export templates и
.NET SDK с поддержкой `net9.0`.

```bash
dotnet build
godot-mono --path .
```

Релизные пакеты создаются командой `./tools/build-release.sh` на Linux/macOS
или `.\tools\build-release.ps1` в PowerShell. Публикация тега `vX.Y.Z`,
совпадающего с версией в `project.godot`, автоматически создаёт GitHub Release
с готовыми установщиками и portable-архивами.
