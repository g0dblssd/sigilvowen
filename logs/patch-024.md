# Патч №024 — фундамент прогрессии героя

Дата: 2026-09-22

## Уровни и классы

- Добавлена модель классов `Runeblade`, `Aetherist`, `Warden`; текущий герой
  начинает как Runeblade, выбор класса будет подключён отдельной панелью.
- Обычная прокачка ограничена 300 уровнем. Каждый уровень выдаёт пассивное очко.
- После 300 уровня XP переходит в бесконечные Paragon-уровни и Paragon-очки.
- Заложены бесконечные ранги Power, Vitality и Haste; Power уже увеличивает
  урон, Haste уменьшает cooldown вплоть до безопасного лимита.

## XP и HUD

- Raider даёт 25 XP, Hexer — 38 XP, Brute — 48 XP.
- HUD показывает класс, уровень, прогресс XP и свободные пассивные очки;
  после 300 уровня переключается на Paragon-информацию.

## Постепенное открытие линков

- В начале доступны `Fire Link`, `Lightning Form` и `Chain Extension`, которые
  используются стартовой раскладкой.
- Остальные линки видны в Link Forge, но заблокированы до победы над хранителем
  подземелья.
- Прогрессия умеет открывать следующий ещё закрытый линк для будущей награды
  босса.

## Проверка

- `dotnet build Sigilwoven.csproj` — успешно: 0 warnings, 0 errors.
- `godot-mono --headless --path . --quit-after 1800` — exit code 0; прогрессия,
  Link Forge, ритуал и стартовая группа созданы без C# / Script Error.
