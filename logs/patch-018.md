# Патч №018 — первые текстуры и анимации боя

Дата: 2026-09-22

## Текстуры

- Добавлена бесшовная тёмная каменная текстура арены с рунными каналами.
- Добавлена красно-чёрная текстура брони рейдера с кожей, металлом и жаром в
  трещинах.
- Материал пола использует восьмикратный UV-повтор и анизотропную фильтрацию.
- Материал рейдера получил шероховатость, металл и мягко пульсирующую эмиссию.

## Модель и анимация рейдера

- У простого тела появились светящийся визор и металлический клинок.
- Во время движения корпус покачивается и слегка подпрыгивает.
- Ближняя атака получила короткий выпад со squash/stretch-анимацией.
- Попадание ближней атаки создаёт отдельную радиальную вспышку у игрока.

## Источник ассетов

Обе исходные PNG-текстуры созданы встроенным генератором изображений специально
для проекта и хранятся в `assets/textures/`.

## Проверка

- `dotnet build Sigilwoven.csproj` — успешно: 0 warnings, 0 errors.
- Чистый `godot-mono --headless --path . --import` — обе PNG импортированы,
  exit code 0, ошибок импорта нет.
- `godot-mono --headless --path . --quit-after 1800` — exit code 0; ритуал
  завершён, 4 текстурированных рейдера созданы, C# / Script Error нет.
