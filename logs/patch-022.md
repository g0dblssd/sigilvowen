# Патч №022 — цели боя и завершение арены

Дата: 2026-09-22

## HUD встречи

- Панель героя расширена постоянной строкой `OBJECTIVE`.
- Во время рождения она показывает обратный отсчёт ритуала.
- В бою отображаются номер текущей волны и число оставшихся противников.
- Между волнами показывается трёхсекундный обратный отсчёт.

## Исправление финала

- Удалён ранний выход, из-за которого после третьей волны игра переставала
  проверять живых врагов и никогда не фиксировала победу.
- После зачистки третьей волны появляется `ARENA CLEARED`, мана полностью
  восстанавливается и выводится финальное сообщение встречи.
- Обновления текста выполняются только при изменении числа, а не каждый кадр.

## Проверка

- `dotnet build Sigilwoven.csproj` — успешно: 0 warnings, 0 errors.
- `godot-mono --headless --path . --quit-after 1800` — exit code 0; HUD ритуала
  и стартовая волна созданы без C# / Script Error.
