# Патч №030 — большой мир, респавн и многоэтажный рейд

Дата: 2026-09-22

## Открытый мир

- Игровая территория расширена с 60×60 до 140×140, а физические стены и
  декоративные Aether-кристаллы перенесены к новому периметру.
- Вместо трёх одноразовых групп мир содержит шесть разнесённых лагерей по
  3–5 противников. После зачистки группа восстанавливается через 14 секунд.
- Первый clear всех шести лагерей один раз открывает Descending Raid.
- На время рейда поверхностная популяция удаляется и ставится на паузу, чтобы
  обычные противники не смешивались с рейдовыми. После босса лагеря возвращаются.

## Descending Raid

- Правая панель запускает повторяемый рейд из трёх этажей.
- На этажах последовательно появляются 3, 4 и 5 агро-групп, по 4, 5 и 6
  противников в каждой. Здоровье врагов растёт с этажом и номером прохождения.
- После третьего этажа появляется усиленный Sigil Guardian.
- Победа над Guardian открывает следующий закрытый Link и следующий навык,
  который обычно потребовал бы уровень. Полученные в рейде навыки сохраняются.
- Когда все награды собраны, дальнейшие прохождения остаются источником XP и
  Paragon-прогресса.

## Проверка

- `dotnet build` — успешно: 0 warnings, 0 errors.
- Обычный `godot-mono --headless --path . --quit-after 1800` — exit code 0;
  ритуал завершён, шесть лагерей созданы без C# / Script Error.
- Отдельный smoke-тест с временным автозапуском рейда создал первый этаж:
  3 группы по 4 врага, exit code 0. Тестовый hook после проверки удалён.
