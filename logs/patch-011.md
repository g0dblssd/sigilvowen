# Патч №011 — косметическая полировка арены и HUD

Дата: 2026-09-21

## Визуал арены

- В центре появилась полупрозрачная ритуальная платформа с внутренним
  светящимся кольцом, чтобы тотем и место рождения героя читались как главный
  фокус сцены.
- Добавлен мягкий синий OmniLight у центра и слабые источники света у четырёх
  обелисков. Они дают глубину и лучше отделяют арену от тёмного фона.

## HUD

- Добавлена затемнённая полупрозрачная панель с заголовком SIGILWOVEN //
  AETHER ARENA.
- Подсказки, выбранный слот, здоровье, мана и боевые сообщения получили
  согласованные позиции, размеры и цвета; логика управления не менялась.

## Проверка

- `dotnet build` — 0 warnings, 0 errors.
- Headless-прогон с отдельными XDG-каталогами: мир строится, ритуал стартует,
  C# / Script Error отсутствуют.
