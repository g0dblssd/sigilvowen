# Патч №025 — группы агро и Echoing Vault

Дата: 2026-09-22

## Группы вместо волн

- Автоматические волны удалены из текущего игрового цикла.
- После ритуала на арене одновременно размещаются три отдельные группы:
  `Ember Raiders`, `Veil Hexers` и `Broken Vow`.
- Каждая группа имеет видимый сигил радиуса агро и остаётся бездействующей,
  пока игрок не войдёт внутрь. После активации вся группа нападает сразу.
- HUD показывает количество оставшихся групп. Зачистка поверхности открывает
  подземелье.

## Панель подземелья

- Справа добавлена постоянная панель `Echoing Vault` с описанием, статусом и
  кнопкой запуска.
- До зачистки поверхности кнопка заблокирована.
- Запуск возвращает героя в центр и размещает три усиленные группы по арене;
  они также активируются только при приближении.

## Босс и награда

- После зачистки трёх dungeon-групп появляется `Sigil Guardian` с 620+ HP,
  увеличенным телом, короной, тяжёлыми атаками и усиленными болтами.
- Босс выдаёт 600 XP и открывает следующий заблокированный Link.
- Подземелье повторяемое: каждый следующий заход усиливает здоровье босса и
  открывает следующую связку, пока коллекция не будет собрана полностью.

## Проверка

- `dotnet build Sigilwoven.csproj` — успешно: 0 warnings, 0 errors.
- `godot-mono --headless --path . --quit-after 1800` — exit code 0; после
  ритуала размещены три dormant-группы, C# / Script Error нет.
