# Патч №012 — hardening и исправление жизненного цикла

Дата: 2026-09-21

## Исправленные баги

- `SpawnSequence` теперь безопасно переживает порядок `AddChild()` / `Setup()`:
  ритуал запускается ровно один раз и больше не может пропустить материализацию
  героя из-за слишком раннего `_Ready()`.
- `SkillCaster` блокирует прямые вызовы каста во время ритуала или после смерти,
  даже если событие ввода пришло в промежуточный кадр.
- `Enemy.TakeDamage` игнорирует удалённые/мёртвые цели и NaN/Infinity-урон;
  цепные попадания больше не продолжают обработку удалённого врага.
- `Projectile` защищён от повторного `BodyEntered` в одном кадре и от сплэша
  по врагу, который уже помечен на удаление.
- `RaiderBolt` и `AetherShard` получили флаги одноразового срабатывания;
  осколок не может восстановить ману несколько раз до deferred deletion.
- Визуальные эффекты молнии больше не используют безусловный null-forgiving
  доступ к `CurrentScene` при завершении сцены.

## Проверка

- `dotnet build` — 0 warnings, 0 errors.
- Headless: мир строится, `[Spawn] Ritual started` появляется корректно,
  C# / Script Error отсутствуют. Godot сообщает только стандартный при
  принудительном выходе leak трёх Shape RID.
