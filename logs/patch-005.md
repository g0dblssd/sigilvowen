# Патч №005 — Волны и приоритеты миньонов

Дата: 2026-09-18

## Сделано

- После очистки стартовой засады игра отсчитывает 3 секунды и создаёт вторую
  волну из 5 рейдеров по 80 HP.
- После второй волны создаётся финальная волна из 6 рейдеров по 105 HP.
- Сообщения HUD предупреждают о следующей волне и объявляют начавшуюся.
- Призывы теперь предпочитают активных рейдеров тренировочному манекену;
  манекен остаётся резервной целью для спокойного тестирования урона.

## Проверка

- `dotnet build` — успешно: 0 warnings, 0 errors.
- Headless-прогон до завершения ритуала прошёл без ошибок C# и `Script Error`.
