# Патч №020 — границы и атмосфера арены

Дата: 2026-09-22

## Новый слой окружения

- Добавлен отдельный `ArenaEnvironment`, который отвечает за физические границы
  и анимированный декор, не раздувая `Main.cs`.
- Четыре невысокие стены из рунного камня ограничивают игровое пространство.
  Их коллизии находятся на слое `World`, поэтому игрок, рейдеры и миньоны не
  могут уйти за пределы боевой площадки.
- По периметру размещены восемь парящих шестигранных Aether-кристаллов.
- Кристаллы медленно вращаются, покачиваются по высоте и дают четыре мягких
  синих источника света вокруг арены.

  ритуал и первая засада созданы без C# / Script Error.
