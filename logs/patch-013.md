# Патч №013 — запуск одной командой

Дата: 2026-09-21

Добавлен исполняемый launcher `sigilwoven`. Он:

- запускается из любой текущей директории;
- сам находит корень проекта относительно расположения launcher;
- предпочитает `godot-mono`, но использует `godot`, если Mono-бинарь называется иначе;
- передаёт все аргументы дальше (`--editor`, `--headless`, `--quit-after` и т.д.).
- корректно разрешает собственный путь даже после установки через симлинк в
  `~/.local/bin`.

Для установки команды в `~/.local/bin` выполните из папки проекта:

```bash
./install-sigilwoven.sh
```

После этого игра запускается командой:

```bash
sigilwoven
```
