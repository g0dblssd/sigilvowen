# Патч №029 — большое интерактивное дерево и блокировка ввода

Дата: 2026-09-22

## Sigil Constellation 2.0

- Дерево расширено с 361 до 1009 узлов на полотне 4000×4000.
- Первые 361 ID сохранены для совместимости с существующими сохранениями;
  новые узлы продолжают прежние 18 ветвей наружу.
- Тысяча отдельных `Button` заменена одной рисуемой картой. Это заметно снижает
  расход памяти и нагрузку на Godot UI.
- При наведении мгновенно появляется собственная подсказка: тип характеристики,
  точный бонус, стоимость, статус и номер требуемого предыдущего узла.
- Milestone-узлы визуально крупнее и дают три ранга за одно очко.

## Блокировка управления

- Открытый Link Forge или Sigil Constellation полностью останавливает движение,
  очищает старую точку назначения и блокирует касты.
- Удержание ЛКМ над интерактивной UI-панелью больше не двигает героя за окном.
- `Escape` закрывает дерево, `P` переключает его состояние.

## Проверка

- `dotnet build Sigilwoven.csproj` — успешно: 0 warnings, 0 errors.
- Отдельный smoke-тест принудительно построил все 1009 узлов с exit code 0;
  временный тестовый hook после проверки удалён.
- Финальный `godot-mono --headless --path . --quit-after 1800` — exit code 0;
  мир и dormant-группы созданы без C# / Script Error и teardown-crash.
