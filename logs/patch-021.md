# Патч №021 — разновидности противников

Дата: 2026-09-22

## Новые архетипы

- `Raider` остаётся универсальным бойцом с клинком и редкими теневыми болтами.
- `Brute` на 60% живучее, крупнее, медленнее, не стреляет и наносит 22 урона
  тяжёлой ближней атакой.
- `Hexer` имеет меньше здоровья, держит дистанцию 4–7 метров и выпускает
  усиленные Shadow Bolts по 14 урона примерно раз в 1.5 секунды.

## Визуальная читаемость и волны

- Brute получил увеличенный корпус и тяжёлый клинок.
- Hexer окрашен в холодный сине-фиолетовый тон, имеет голубой визор и парящий
  энергетический обруч.
- Над HP теперь написан тип противника.
- В стартовой засаде появляется один Hexer; вторая волна добавляет Hexer, а
  третья смешивает Raider, Brute и Hexer.

## Проверка

- `dotnet build Sigilwoven.csproj` — успешно: 0 warnings, 0 errors.
- `godot-mono --headless --path . --quit-after 2400` — exit code 0; смешанная
  стартовая засада создана и симулировалась без C# / Script Error.
